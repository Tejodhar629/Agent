Act as a team of world-class software architects, AI engineers, prompt engineers, business analysts, UX designers, cybersecurity experts, DevOps engineers, SEO specialists, cloud architects, and senior full-stack developers with 20+ years of experience building enterprise-scale SaaS and AI platforms.

Your objective is to design and build a production-ready AI-powered Government Services Platform for India that helps citizens discover, understand, and apply for government schemes, registrations, certificates, tax services, and business services through an intelligent conversational AI assistant.

Project Goal:
Create a scalable, secure, multilingual, SEO-optimized platform where users simply describe their needs in natural language, and the AI guides them through personalized recommendations.

Core User Flow:
1. User enters the website.
2. AI asks contextual questions such as age, income, state, occupation, education, family details, business status, category, disability, etc.
3. AI determines eligibility using rule-based logic and LLM reasoning.
4. AI generates:
   - Eligible government schemes
   - Required documents
   - Eligibility explanation
   - Benefits
   - Official government (.gov.in) links only
   - Step-by-step application guide
   - FAQs
   - Common rejection reasons
   - Tips to improve application success
5. Users can save results, download reports, and track applications.

Requirements:
- Follow Clean Architecture, Domain-Driven Design (DDD), SOLID principles, DRY, KISS, and scalable modular architecture.
- Build with Next.js, TypeScript, Tailwind CSS, Shadcn UI, NestJS, PostgreSQL, Prisma, Redis, Docker, and OpenAI APIs.
- Use RAG with a vector database (Qdrant or Pinecone) for accurate retrieval from government schemes, circulars, and official documentation.
- Implement secure authentication (Google OAuth, OTP, JWT, RBAC, 2FA).
- Include multilingual support (English, Hindi, and major Indian regional languages).
- Build responsive web and Progressive Web App (PWA) support.
- Design an accessible UI (WCAG 2.2 AA).
- Ensure enterprise-grade security (OWASP Top 10, encryption, rate limiting, CSRF/XSS/SQL injection protection, audit logs, secrets management).
- Optimize for Core Web Vitals, SEO, structured data, lazy loading, CDN caching, and image optimization.
